# [Steam] Custom Add Funds Button

A userscript that allows you to customize the Steam Wallet Add Funds button.

**Note:**
- This script only works on the [Steam Wallet Add Funds page](https://store.steampowered.com/steamaccount/addfunds).
- You cannot add funds in amounts lower than the minimum amount specified by Steam.

## Requirements

This script requires **[Tampermonkey](https://www.tampermonkey.net/)** to be installed in your browser.

### Download Tampermonkey

Choose your browser to download Tampermonkey:

- [Google Chrome](https://www.tampermonkey.net/?browser=chrome)
- [Mozilla Firefox](https://www.tampermonkey.net/?browser=firefox)
- [Microsoft Edge](https://www.tampermonkey.net/?browser=edge)
- [Opera](https://www.tampermonkey.net/?browser=opera)
- [Safari](https://www.tampermonkey.net/?browser=safari)

## Installation

1. Install Tampermonkey for your browser.
2. Click the installation link below.
3. Tampermonkey will open the script installation page.
4. Click **Install** to finish the installation.
