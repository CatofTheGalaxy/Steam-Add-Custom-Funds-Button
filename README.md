# [Steam] Custom Top-Up Button

A Tampermonkey userscript that adds a custom amount input and an **Add Funds** button to the Steam Wallet Add Funds page.

## Features

- **Custom Amount:** Enter your own Steam Wallet top-up amount.
- **Minimum Amount Validation:** Prevents entering an amount lower than Steam's minimum allowed amount.
- **Quick Submission:** Submit your custom amount by clicking the Add Funds button or pressing Enter.
- **Currency Detection:** Automatically detects and displays your Steam Wallet currency.
- **Steam Integration:** Uses Steam's existing Add Funds functionality to process the request.

## Requirements

- A browser with [Tampermonkey](https://www.tampermonkey.net/) installed.
- A Steam account.

## Compatibility

This script only works on the following page:

[Steam Wallet Add Funds](https://store.steampowered.com/steamaccount/addfunds)

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/) in your browser.
2. Open the script installation link below.
3. Click **Install** in Tampermonkey.

## Notes

- You cannot add funds in amounts lower than the minimum amount specified by Steam.
- All transactions are handled through Steam's existing payment system.
- This script only customizes the Add Funds interface and does not bypass Steam's payment restrictions.
